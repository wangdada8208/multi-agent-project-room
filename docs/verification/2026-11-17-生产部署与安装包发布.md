`publish-downloads.yml`（workflow_dispatch）完成。过程中发现并绕过三个坑：

1. runner → GitHub release 资产 CDN（objects.githubusercontent.com）不通
   （curl 52 空回复）。改为把 72K 的 tar.gz 打进一次性运维分支
   `ops/publish-helper-pkg` 的 `release-pkg/`，随 `actions/checkout` 落地

   nginx 补丁脚本；`/downloads/` location 本就已存在，跳过补丁。
3. **关键**：工作流原以为服务目录是 `/var/www/hub-downloads`，
   `nginx -T` 实测真实配置是 `alias /www/migrated/hub-downloads/`
   （技能包实际也在那里）。改到真路径后 HEAD 200。
   误建的 `/var/www/hub-downloads` 已在同一步骤内清理。

GitHub Release `mapr-helper-v0.1.0`（tag 于 `9a944c39`）挂了同一份 tar.gz 与
