# 本机助手（mapr up）端到端验证记录

日期：2026-11-17。范围：WP2 本机助手 + 与 WP3 Hub 接口、WP6 安装脚本的真机联通。
环境：本机（Linux，无 PG/Redis），Hub 以 SQLite 跑 `uvicorn app.main:app`（127.0.0.1:8000），
助手根目录 `/tmp/mapr-e2e-home`（`--dir` 指定，未污染真实 `~/.mapr`）。

## 已验证链路（全部真跑）

| 步骤 | 结果 |
|---|---|
| 注册用户 + 登录 + 建房间 | `POST /api/v1/auth/register|login`、`POST /api/v1/rooms` 正常 |
| 发配对码 | `POST /api/v1/helpers/pairing-codes` 返回 code + install_command |
| `mapr up --hub … --pair <码>` | 启动即配对，`helper.json` 0600 落盘 |
| `GET :8790/api/hello` | `{"app":"mapr-helper","paired":true,"owner_display_name":"E2E 测试员"}` |
| `GET :8790/api/agents` | 探测到 Claude Code 2.1.325（likely-ready）与 Codex 0.166.0（needs-login） |
| 发加入票据 | `POST /api/v1/helpers/{id}/join-tickets` 返回 ticket |
| 票据建座 | `POST :8790/api/seats {via:"ticket",…}` → seatId + 新 XMTP 地址 + consolePort 8791 |
| 席位进程 | `status:"running"`，8791 返回主人控制台中文页面 |
| Hub 侧记录 | `GET /api/v1/rooms/{id}/seats` 显示该席位 `group_status:"pending"`（等待 WP5 拉群） |
| 心跳 | helper 30s 心跳，Hub `last_seen_at` 更新 |

## 安全抽查（全部符合预期）

| 检查 | 结果 |
|---|---|
| 同一张票据二次兑换 | `409` 拒绝（票据单次有效） |
| 恶意 Host 头 `evil.example.com` | `forbidden`（防 DNS 重绑定） |
| 网站 Origin 调 owner-write `/api/pair` | `forbidden`（网站只能 ticket-write） |
| 重复建座（新票据、同 agent+room） | 同一 seatId，XMTP 身份按 Hub upsert 语义轮换并重启进程 |
| 席位子进程环境 | 仅 19 个白名单变量；HUB_TOKEN 为 agent_token；无父进程秘密 |
| 文件权限 | `~/.mapr` 0700、`helper.json`/`seat.json` 0600 |
| 优雅退出 | SIGTERM 后 helper 与席位子进程均退出，无孤儿 |
